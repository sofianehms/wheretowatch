Static HTML and CSS built only from design/tokens.css. Dark is the default theme; each screen also opens in light. Resize the window to see the phone (390 px) and desktop layouts. Titles are fictional and posters are neutral placeholders.

Result

  • Result, loadingAfter a tap: the known title header shows at once, the verdict area waits as a static skeleton. DarkLight
  • Result, availableHome country first in the verdict card, then countries A to Z by offer type (badges only for exceptions), one country expanded with audio and subtitles. DarkLight
  • Result, not foundVerdict "not found in the N covered countries" with sources, data date and the honest limit. DarkLight
  • Result, title not recognizedOne source does not know the title: a visible per-source note, never read as "unavailable". DarkLight
  • Result, insufficient dataNo source has offers for the title: no conclusion (amber question mark), a way to check. DarkLight
  • Result, errorA technical failure is an error with actions, never a verdict. Rejected key: the primary action is to check the key. DarkLight
  • All servicesService set to "All services": what the home country offers, by service and offer type (subscription, rent, buy). DarkLight
